# API для кафе

Учебный проект в Забайкальском государственном университете, представляет собой бэкенд для управления небольшим кафе.

## Основные возможности

$`\color{yellow}*`$ Создание, чтение, обновление и удаление блюд и категорий меню;<br>
$`\color{yellow}*`$ Управление заказами посетителей;<br>
$`\color{yellow}*`$ Аутентификация пользователей (разграничение прав по ролям) через `API`;<br>
$`\color{yellow}*`$ Административная панель `Django` для управления данными.

## Технологии

$`\color{yellow}*`$ `Python`<br>
$`\color{yellow}*`$ `Django` · `Django Ninja`<br>
$`\color{yellow}*`$ `MySQL`

## Лицензия

Данный проект создан в образовательных целях и не имеет специальной лицензии.
